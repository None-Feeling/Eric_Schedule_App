# Eric Schedule App · Android

> 当前仓库版本：**v1.3.1**（2026-09-19 已重新同步到 `main`）

这是一个原生 Android 课表 App，支持西南大学教务课表 PDF 导入。

## v1.3 更新
- 日程页重做为周视图课表，更接近真实课表 App。
- 整体改成清新蓝绿系，降低粉色占比。
- 顶部日期、周次切换与课程卡片配色重新优化。
- 列表页同步更新为统一的清爽配色。
- 继续支持 PDF 导入，导入后可重新选择第一周周一日期。
- 学期起始仍按 2026-08-31（周一）= 第 1 周。

## 功能
- 自动定位当前周。
- 支持单周 / 双周 / 指定周课程过滤。
- 支持周视图日程、列表视图双模式切换。
- 展示课程名、节次、时间、教室、教师、课程类型。
- 点击课程卡片查看完整详情。
- 本周总览。
- 全程离线，不需要登录和网络权限。

## 技术参数
- Java
- minSdk 23
- targetSdk 35
- compileSdk 35
- PDF 解析：com.tom-roush:pdfbox-android:2.0.27.0
